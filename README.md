# Puterea-prezentului
Știi acel moment când te trezești dimineața și primul gând este deja îngrijorat? Sau când mintea ta pornește singură pe scenarii pe care nu ți le-ai dorit?  Te înțeleg. Am fost și eu acolo.  Puterea Prezentului s-a născut exact din acel loc — din nevoia de a avea ceva concret în mână în momentele grele.
